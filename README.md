# 당신 안의 S성향을 꺼내보세요

세 캐릭터 중 하나를 골라 **왼쪽 뺨 / 정면 / 오른쪽 뺨**을 눌러보는 브라우저 미니 시뮬레이션입니다.

## 적용된 캐릭터

사용자가 전달한 이미지 3장을 아래와 같이 적용했습니다.

- **평평이** → 첫 번째 첨부 이미지
- **버럭이(버럭씨)** → 두 번째 첨부 이미지
- **아방이** → 세 번째 첨부 이미지

세 이미지는 `characters/*.png` 파일로 정리되어 있으며, 배경을 제거한 투명 PNG로 들어 있습니다.

## 기능

- 캐릭터 3명 선택
- **왼쪽 뺨 / 정면 / 오른쪽 뺨** 펀치
- 캐릭터별 다른 반응
  - **버럭이**: `갑자기 왜 때려!`, `장난하냐!` + 💢
  - **아방이**: `왜 그래...`, `아파....` + 💧
  - **평평이**: `으악!`, `으악, 으악!`
- 최근 리액션 기록
- 총 펀치 횟수 / 캐릭터별 맞은 횟수
- 효과음 ON/OFF
- 키보드 조작 지원 (`A` / `S` / `D`)
- 모바일 / 데스크톱 반응형 지원

## 파일 구조

```text
punch-lab/
├─ index.html
├─ style.css
├─ script.js
├─ README.md
└─ characters/
   ├─ beoreok.png
   ├─ abang.png
   ├─ flat.png
   ├─ beoreok.svg
   ├─ abang.svg
   └─ flat.svg
```

`.png` 파일이 실제 적용 이미지이며, `.svg` 파일은 예비용 기본 캐릭터입니다.

## 실행 방법

그냥 `index.html`을 브라우저로 열어도 되고, 로컬 서버를 써도 됩니다.

```bash
python -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 접속.

## GitHub Pages 배포

1. GitHub에 새 저장소 생성
2. 이 폴더 안의 파일 전체 업로드
3. **Settings → Pages** 이동
4. **Deploy from a branch** 선택
5. **main / (root)** 선택 후 저장

배포가 끝나면 GitHub Pages 주소에서 바로 확인할 수 있습니다.
